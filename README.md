# 150cau-trr1

Trang tự luyện 150 câu Toán rời rạc theo giao diện DLab của CodePTIT.

- Toàn bộ giao diện, CSS, JavaScript, câu hỏi và ảnh được gói trong `index.html`.
- Lựa chọn và câu đánh dấu được lưu trên trình duyệt; có thể xuất hoặc nhập JSON để chuyển tiến độ.
- Bản gốc không có đáp án chuẩn, nên trang không tự chấm điểm.

## GitHub Pages

Trong repository, vào **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, nhánh **main** và thư mục **/(root)**. Sau khi xuất bản, trang sẽ nằm tại `https://arokepg.github.io/150cau-trr1/`.
